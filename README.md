# MechlandsGarage

A Flask-powered automotive platform built for the Kenyan market.

Live Demo: https://shockey01.pythonanywhere.com/

## What it does

MechlandsGarage connects car owners in Kenya with trusted mechanics, garages, and automotive services.

- Browse garages and mechanics by location
- View services, pricing in KES, and ratings
- Book / request a service
- Admin dashboard to manage garages and services

## Tech Stack

- Backend: Python, Flask, SQLAlchemy
- Frontend: HTML, CSS, JavaScript
- Deployment: PythonAnywhere

## How to run locally

```
git clone https://github.com/shockey001/MechlandsGarage.git
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000
